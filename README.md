# cub3D
#### A RayCaster with miniLibX

<br>

## Description

cub3D is a ray-casting project written in C using MiniLibX. It renders a
first-person 3D view from a `.cub` scene file.

## Instructions

Build the project:

```sh
make
```

Run it with a scene file:

```sh
./cub3D maps/valid/subject_map.cub
```

Clean build files:

```sh
make clean
make fclean
make re
```
